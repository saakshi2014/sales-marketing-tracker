# Sales & Marketing Performance Tracking System

**Masters Level Project — 2025–26**
Mahatma Gandhi Memorial College, Udupi

---

## About

A centralized web-based platform for sales and marketing performance tracking.
Built with three user roles: Employee, M1 Manager, and M2 Manager.

**Features:** Lead pipeline · Task management · KPI dashboards · Visual charts

---

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | HTML5, CSS3, JavaScript, Bootstrap 5 |
| Backend | Python (Flask) |
| Database & Auth | Firebase (Firestore + Authentication) |
| Deployment | Docker (on-premises) |

---

## How to Run Locally

### Step 1 — Clone the project
```
git clone https://github.com/YOUR-USERNAME/sales-marketing-tracker.git
cd sales-marketing-tracker
```

### Step 2 — Set up your .env file
```
copy .env.example .env
```
Then open `.env` and fill in your Firebase credentials (see Day 2 setup).

### Step 3 — Start the application
```
docker compose up --build
```

### Step 4 — Open in browser
```
http://localhost:5000
```
